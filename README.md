# 💰 CashPilot

An AI-powered personal finance management platform built using the MERN Stack. CashPilot helps users track income, manage expenses, monitor savings, and receive personalized budgeting insights through an AI Budget Coach.

## 🚀 Features

* Secure JWT Authentication
* Income & Expense Management
* Financial Dashboard & Analytics
* AI Budget Coach (Groq + Llama)
* Interactive Charts & Reports
* Dark / Light Mode
* Fully Responsive Design

## 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS, Recharts

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Authentication:** JWT, bcrypt

**AI Integration:** Groq API (Llama Models)

## ⚙️ Installation

```bash
git clone https://github.com/arambh8960/CashPilot.git
cd CashPilot

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

Create a `.env` file in the backend directory:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GROQ_API_KEY=your_groq_api_key
```

## 🎯 Project Goal

To simplify personal finance management by combining expense tracking, financial analytics, and AI-powered budgeting assistance in a single platform.
